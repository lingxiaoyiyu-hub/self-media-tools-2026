## 一、写作类：通用大模型 vs 写作工作台

**通用大模型**（DeepSeek、豆包、通义等）适合从零讨论、改单段、想标题。缺点是：每次要自己贴提示词；写完还要自己配图、排版、发布。

**写作工作台**（零创）把“选题 → 写稿 → 配图 → 发布”串起来：按今日头条、公众号、知乎、小红书文风生成，支持两遍式写作、自定义提示词、目标字数；写完可以直接进发布流程。

- 适合：每天要更几条、需要稳定产出与发布的人。
- 不适合：只想偶尔让 AI 写一段、不需要发布的人。

## 二、降 AI 类：通过朱雀检测

搜“降 AI 味”，常见两类方案：

1. **在线 humanizer**（如 Wordvice）：粘贴文本返回改写，按字数收费，原文要上传。
2. **通用大模型提示词**：让模型“写得更像人”，结果不稳定，长文容易截断。

零创的「必过朱雀」走本地端侧模型：两档改写强度（自然通顺 / 深度破碎）、逐段对照、单段精修，改写前后可拿朱雀复测。我们做了几百次测试，改写后 100% 通过，无一例外；实测截图见专题页。

## 三、图文成片 / 文章转视频

在线 SaaS 的代表：度加（百度）、TapVid、Leadde、Pollo、Fableclip、FlexClip、Kapwing、Vivideo。它们的共同点是：上传文章 → 在线生成 → 订阅/水印/排队。

零创的差异是**本地批量**：文章或口播稿自动拆分镜、逐段出图或调用素材、14 款中文音色配音、双行字幕、8 首 BGM，本机合成 MP4；成片直接进视频成果库，不排队、不上传。

- 适合：每天批量出片的自媒体。
- 不适合：只做一条、且对画面精细度要求很高的人（这类用专业剪辑更合适）。

## 四、视频二创 / 去水印 / 变声

常见方案：

- **在线去重网站**：改 MD5、加滤镜、变速，素材要上传，参数固定。
- **手动剪辑（剪映等）**：精细可控，但一条条做，批量效率低。
- **开源脚本（如 GitHub 上的 toutiao-auto-publish、AIMedia）**：能自动化，但需要环境配置，平台改版后容易失效。

零创把二创做成可视化工作台：裁头尾、变速、随机裁剪缩放、微旋转、镜像、色调扰动、音频指纹扰乱、去水印（自动识别/手动框选）、22 款变声，支持批量处理，原片保留。

- 适合：有大量已授权素材、需要批量降重出片的人。
- 注意：二创不能替代版权授权，搬运他人作品仍有风险。

## 五、公众号写作与排版

常见工具：

- **排版编辑器**：壹伴、排版鸭、墨格等，强在排版与素材，弱在写稿与草稿流程。
- **AI 写作站**：WechWriter 等，强在生成，排版与图片仍要手工搬。
- **零创**：公众号文风写作 + 28 套排版主题 + 配图转微信图床 + 一键存草稿 + 多账号台账。

边界：微信接口只到草稿箱，最后一步仍需在公众号后台点发布。

## 六、头条 / 微头条批量发布

常见方案：

- **手工发**：一条条复制，账号多了容易漏、容易串号。
- **开源自动化脚本**：能批量，但配置门槛高，平台改版就可能失效，出问题不好排查。
- **零创**：可视化批量发布，头条 / 微头条 / 百家号 / 公众号统一管理；账号登录态物理隔离；支持按账号分槽定时，重复排期会被拦下；发布结果逐篇核验。

- 适合：一人管多个账号、每天要稳定更新的工作室。
- 注意：不要相信“防封”“无限发文”这类承诺，平台规则始终优先。
